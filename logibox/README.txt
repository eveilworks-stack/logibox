LOGIBOX ver.0.72（内部バージョン0.7.2）

これまでの修正をすべて含む配布版です。
・案件一覧の検索・進捗絞り込み・並び順選択欄を削除。
・一覧見出しの「納期」「進捗」をクリックして昇順／降順を切り替え。
・下請けの「充当解除・参加リセット」から、理由を記録して訂正。
・充当だけ解除、または充当解除と案件参加リセットを選択可能。
・解除した充当は充当元の利用可能額へ戻します。
・元金請求書は取消済みにし、原本PDF・旧版・理由を保持。新規発行も可能。
・銀行口座切替、案件証憑整理・一式PDFなど従来の機能も含みます。

同梱データ
このチャットに添付された「LOGIBOX_ver0.70_配布用_登録データ入り.zip」の
業務dataフォルダは同梱していません。既存環境は更新専用ZIPで更新してください。
会社情報・社印・下請け2社・仕入先2社と元のバックアップを含みます。
案件・発行済み帳票は0件です。現在利用中のPCのデータを取得したものではありません。

起動する場合
1. ZIPをすべて展開してください。
2. Windowsはlogibox内の「起動.vbs」、Macは「start.command」を開いてください。
3. パスワードが未設定の場合は、初回画面で設定してください。
Python 3.10以降が必要です。Windowsの初回起動では必要なライブラリを準備します。

利用中のデータを保持して更新する場合
1. 利用中アプリで「添付書類を含む全体バックアップ」を保存してください。
2. このZIPを利用中アプリとは別のフォルダへ展開してください。
3. 展開したlogibox/update.batを開き、現在使用中のlogiboxフォルダを選んでください。
   Macでは python3 update.py --target "/path/to/current/logibox" を使用します。
4. 更新後は、現在使用中のlogiboxフォルダから起動してください。
同梱のdataで利用中のdataを上書きしないでください。
詳細は「更新手順.txt」を参照してください。

充当解除・参加リセット
対象案件の「下請け」タブから「充当解除・参加リセット」を開きます。
操作を選び、解除額と取消対象請求書を確認し、理由を入力して実行します。
実入金・回収返金・後続充当・依頼済み以降の精算がある場合は、関連取引の確認が必要です。
変更前のDBを自動バックアップし、失敗時は一括で取り消します。

会社情報・社印・取引先情報を含む私用配布版です。

ver.0.72：案件・下請け別の利益精算（通常／都度）を追加。
支払予定と実績を分離し、月次精算で支払済み・別途予定を控除。
利益精算操作手順.txt、ver0.72実装・テスト報告.txtを参照してください。
