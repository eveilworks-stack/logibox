## 今回の修正

- 0.6.6のまま残っていた画面表示を修正。ログイン画面とログイン後にver.0.67を表示。
- 起動済みサーバーの版・コード・起動フォルダ・データ保存先を照合し、旧版への誤接続を防止。
- 既存フォルダ全体のバックアップと照合を完了してから、コードだけを更新。
- 更新したプログラムに対応するPythonキャッシュだけを、バックアップ後に無効化。
- 0.6.7の請求依頼文編集・保存と、既存の元金・充当・帳票機能を維持。

## 既存データを保持する更新

**更新専用パッケージです。DB・パスワード・社印・案件・発行済みPDF・バックアップを含みません。元の「案件リセット版」のDBを利用中のdataへコピーしないでください。**

1. 利用中アプリの「設定→バックアップ」で全体バックアップを保存します。外部のPDFコピー先も保管してください。
2. PCを再起動し、LOGIBOXはまだ開きません。ブラウザを閉じるだけでは旧サーバーは終了しません。
3. 新しいZIPを利用中フォルダとは別の場所へ展開し、`logibox/update.bat`を開きます。Python 3.10以降が必要です。
4. 現在のデータがある利用中の`logibox`フォルダを選択します。`data/app.db`が必要です。
5. 更新ツールが停止状態・配布ファイルを確認し、フォルダ全体を隣接する`LOGIBOX-before-0.6.7-*/full-installation.zip`へ保存・照合してからコードを更新します。
6. 更新が完了したら、更新済みの利用中フォルダにある`起動.vbs`を開きます。デスクトップのショートカットも更新されます。
7. ver.0.67の表示と、会社情報・案件・請求書・入金・元金・充当履歴・PDFを確認します。

`APP_DATA`でデータ保存先を変更している場合は、自動更新を中止します。環境変数を安易に消さず、管理者が実データの保存先とバックアップを確認してください。

空の更新パッケージから直接起動しても、新しいDBは作成しません。詳しい中止条件・復旧方法は同梱の更新手順を参照してください。
