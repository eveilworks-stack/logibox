# LOGIBOX

Windowsで使うTOMOS向けの案件・仕入・請求書・月次精算管理アプリです。

**最新版：ver.0.6.5（2026-11-20 / DBスキーマ12）**

[データなし版ZIPをダウンロード](./LOGIBOX_latest_no_data.zip?raw=1)

ソースは `logibox/` にも収録しています。登録データ・パスワード・社印・証憑・発行済みPDF・バックアップは含みません。
フォント、未記入の公開済み帳票テンプレート、起動ファイル、自動テストを含みます。アプリ標準の取引先名は含みます。
帳票配置テストの連絡先・口座の例は架空値に置き換えています。

## 0.6.5の修正

- ダッシュボードと案件候補の充当可能額を共通計算し、元金・一時預かり金を自動一覧表示。
- 納期順だけの除外を廃止し、複数案件への部分充当を維持。未回収・使用済み・残高超過・重複・循環は拒否。
- 旧方式の預かり金も候補表示し、選択時に元明細を変更せず台帳へ引き継ぐ。
- 新規入金のみ／他案件／一時預かり金／併用の4方式。上部に金額を表示し、履歴・台帳・返金・上限は詳細へ集約。
- 未確認の新規入金は予定として記録。実入金確認後に元金へ反映。手渡しでは領収書・印紙の確認を必須化。
- 充当元・先の案件番号と案件名、下請け名を履歴へ固定保存し、月次メール・CSVへ反映。

元金残高・入金台帳・仕入手入力・帳票レイアウト・PDF保存など0.6.4までの改修も含みます。
詳細は `logibox/元金登録・充当修正_0.6.5_報告.md` を参照してください。

## 初回起動

1. ZIPをすべて展開し、Python 3.10以降を用意します。
2. `logibox/起動.vbs` を開きます。ライブラリの初回準備にはネット接続を使う場合があります。
3. 初回パスワードと会社情報を設定します。

通常は `http://127.0.0.1:8766/` で利用します。
パスワード復旧は `logibox/パスワード再設定.vbs` を使用します。

## 既存データを引き継ぐ更新

1. 利用中アプリで全体バックアップを取得し、アプリを終了します。
2. 新しいZIPを別フォルダへ展開します。
3. **初回起動前に、旧版のdataフォルダ全体を新しいlogibox内へコピーします。**
4. 外部のPDFコピー先も保管し、新版を従来のパスワードで開いて会社情報・社印・案件・PDFを確認します。

空のDBで既存データを置き換えないでください。初回起動時にバックアップ後、スキーマ12へ追加移行します。
スキーマ12のDBを旧版で開かないでください。戻す場合は変更前のコードとDBを組で復元します。
再起動後はログインし直してください。
