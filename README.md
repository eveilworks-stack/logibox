# LOGIBOX

Windowsで使う案件・仕入・請求書・月次精算管理アプリです。

**最新版：ver.0.6.2 改修版（2026-11-19 / DBスキーマ8）**

[データなし版ZIPをダウンロード](./LOGIBOX_latest_no_data.zip?raw=1)

## この公開版に含むもの

アプリ本体、フォント、未記入の帳票テンプレート、起動ファイル、自動テスト。
アプリ標準の取引先名は含みます。

会社の登録情報、担当者・下請けの登録情報、案件・入出金・精算データ、社印画像、
証憑PDF、ログインパスワード、個別の作業レポート、バックアップは含みません。

## 起動

1. ZIPをすべて展開します。
2. Python 3.10以降を用意します。
3. 展開先の `logibox/起動.vbs` を開きます。
4. 初回パスワードと会社情報を設定します。

初回のライブラリ準備にネット接続が必要な場合があります。
通常は `http://127.0.0.1:8766/` で利用します。

## 既存データを引き継ぐ更新

1. 旧アプリの設定で全体バックアップを保存。
2. PCを再起動し、旧アプリを開かず、新しいZIPを別フォルダへ展開。
3. **初回起動前に、旧版の `data` を新版の `logibox` 内へ丸ごとコピー。**
4. 新版の `起動.vbs` を開き、従来のパスワードでログイン。
5. 案件・PDF・会社情報を確認し、以後は新版を利用。

登録済みの社印は、引き継いだDBの保存値を使用します。

## 今回の主な改修

- 請求依頼文面・PDFひな形・税内訳・担当者宛名。
- 元金充当の編集、変更前DBバックアップ、変更前後の履歴、同時編集の検知。
- 納期が後の同月案件への充当、二重充当と元金二重計上の防止。
- 関連記録がある案件の削除拒否と日本語の原因表示。
- PDFコピー先の設定・環境変数指定。
- 既存PDFと利益計算ルールを維持。

公開ZIPの初期状態と、95件のテスト（93件成功、原本サンプル未配置2件スキップ）、
基本HTTP APIを確認済みです。SHA-256は `SHA256SUMS.txt` で確認できます。
