## ver.0.73

都度精算で「返還可能な元金も精算する」を選択できます。対象案件・下請けの利益と元金を分けて記録し、支払合計を表示します。

- 例：未精算利益30万円＋返還可能元金500万円＝支払合計530万円。
- 利益だけの精算、利益完了後の元金だけの返還に対応。利益の任意金額・一部精算はありません。
- 充当可能額は元金の一部です。別途加算せず、充当済み・予約済み・一時預かり金を自動で合算しません。他案件・他下請けの資金を混ぜません。
- 予定では元金を予約し、実支払時に残高を減らします。月次支払と他案件への充当の二重使用を防ぎます。
- 表示後の残高変更時は再確認を求め、追加回収があっても既存予定の金額を勝手に増やしません。
- 都度精算書PDFに利益・元金・合計を分けて記載。契約率・前回累計は内部だけに保持し、金額は通常サイズです。
- 旧データ・旧PDF・修正履歴を保持します。ver.0.72の既存利益精算へ元金返還を勝手に追加しません。

通常精算（月末締め・翌月15日払い）、既存の利益計算、元金・預かり金台帳、固定帳票テンプレートを維持します。

## 更新と検証

既存環境には更新専用ZIPを使い、利用中のdata/app.dbがあるlogiboxフォルダを指定してください。更新前とDB移行前にバックアップを取得します。公開ZIPには業務DB・社印・既存発行書類を含めません。

28テストファイル、unittest 299件（296成功・3スキップ・失敗0）とAPI検証を実施。新規26件には元金返還・予約・取消、二重使用防止、金額の再確認、移行、PDF、CSV、同時実行を含みます。

```sh
cd logibox
python3 run_tests.py
```

Linux上でブラウザ操作、PDF表示、データ保持更新、新規ZIPの初回起動を確認しました。Windows/macOS実機の確認は未実施です。
