## ver.0.72

- 通常精算は従来どおり月末締め・翌月15日払い。
- 案件・下請けごとに都度精算を追加。対象案件の未精算利益全額を精算し、他の案件・下請けには影響しません。一部精算と任意金額の支払登録はありません。
- 支払予定と支払完了を分離し、過去の実績登録に対応。月次支払から個別支払と別途予定を控除します。
- 個別利益精算書PDFのプレビュー・発行・保存版の閲覧。契約利益率・前回累計をPDFに表示せず、内部には保持します。今回の精算額も通常の文字サイズです。
- 締め後の支払、取消・修正・訂正版の履歴を保持。状態絞り込み、下請け別集計、CSV出力に対応。

既存の元金・預かり金台帳、固定請求書・領収書テンプレートを維持します。
公開配布物には業務DB・社印・発行済み書類を含めません。更新時は利用中フォルダを指定し、同梱データで置き換えないでください。

## 検証

27テストファイルを個別実行し、unittest 273件（270成功・3スキップ・失敗0）とAPI検証を実施。新機能の22件には案件全額精算、部分額の拒否、締め後の二重払い防止、予定と実績の分離、PDF、移行、同時実行を含みます。
