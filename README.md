# LOGIBOX

Windowsで使うTOMOS向けの案件・仕入・請求書・月次精算管理アプリです。

**最新版：ver.0.6.4 改修版（2026-11-20 / DBスキーマ11）**

[データなし版ZIPをダウンロード](./LOGIBOX_latest_no_data.zip?raw=1)

## 公開版の内容

アプリのPython・HTML・JavaScriptソース、フォント、未記入の帳票テンプレート、
起動ファイル、自動テストをZIP内の `logibox` に収録しています。
アプリ標準の取引先名は含みます。

登録済みの会社情報・下請け・案件・入出金・精算・パスワード・社印、
証憑PDF・発行済みPDF・バックアップ・個別作業レポートは含みません。
帳票配置テストの連絡先・口座情報は架空の値に置き換えています。
帳票テンプレートは、作業元と文字・描画結果の一致を確認した既存の公開済み版を維持しています。

## 今回の主な変更

- 元金残高・回収済額・充当可能額を分離し、二重返金や残高超過を防止。
- 元金の複数案件への分割充当、複数元案件・一時預かり金・新規入金の併用。
- 一時預かり金の発生・充当・取消・返金履歴と、入金方法・承諾・領収確認を記録。
- 台帳の追記型履歴、競合・重複登録の防止、月次精算・CSVへの反映。
- 関連記録を保護する案件取消と、従来の充当・入金記録との互換処理。
- PDFなしの仕入手入力、仕入先の新規登録、PDF読取失敗時の入力保持。
- 帳票の会社情報の行詰めと、振込口座の配置を修正。
- DBスキーマ11へのバックアップ付き追加移行とパスワード復旧対応。

従来のPDF保存フォルダ簡略化、原本・旧版の保持、利益計算も継続しています。

## 初回起動

1. ZIPをすべて展開し、Python 3.10以降を用意します。
2. `logibox/起動.vbs` を開きます。必要なライブラリの初回準備にはネット接続を使います。
3. 初回パスワードと会社情報を設定します。

通常は `http://127.0.0.1:8766/` で利用します。
パスワード復旧には `logibox/パスワード再設定.vbs` を使用します。

## 既存データを引き継ぐ更新

1. 旧アプリの設定で全体バックアップを保存し、アプリを終了します。
2. 新しいZIPを別フォルダへ展開します。
3. **初回起動前に、旧版の `data` フォルダ全体を新しい `logibox` 内へコピーします。**
4. PDFコピー先を外部フォルダに設定している場合は、そのフォルダも保管します。
5. 新版を起動し、従来のパスワードでログインして案件・会社情報・社印・PDFを確認します。

空のDBで既存データを上書きしないでください。移行時にはバックアップを取得して
スキーマ11へ更新します。スキーマ11のDBを旧版アプリで開かないでください。
戻す場合は変更前のコードとDBを組で復元します。

2件スキップ（任意の実PDFサンプル未配置）、失敗0件。HTTP APIスモークテストも成功しました。
JavaScriptファイルとHTML内スクリプトの構文検査、データなし初期状態も確認しています。
