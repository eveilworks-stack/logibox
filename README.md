## ver.0.70 の追加機能

- 自社の振込先を3口座登録し、下請け向け元金請求書などの作成時に選択。発行済みは履歴を残して口座変更・再発行できます。
- 「LOGIBOX PDF」を、納期の年 → 管理番号・案件番号・案件名 → 仕入・下請け・ハーク・その他の証憑に整理。
- 各案件の「00_証憑一覧.pdf」と「案件証憑一式.pdf」を自動更新。一式PDFは一覧と現在版の証憑をまとめ、しおりから各書類に移動できます。
- 月次精算の受領請求書は共通フォルダに1部保存し、関連案件の一覧に参照先を記載。複数案件の金額を一式PDFへ重複収録しません。
- 案件管理に納期順・進捗順の並び替えを追加。検索・絞り込みと併用でき、同じブラウザで並び順を記憶します。

```text
LOGIBOX PDF/
├ 2026年/
│ └ 26-0002_案件番号_案件名/
│   ├ 00_証憑一覧.pdf
│   ├ 案件証憑一式.pdf
│   ├ 01_仕入/
│   ├ 02_下請け/
│   ├ 03_ハーク/
│   └ 04_その他/
└ 月次精算/2026-11/下請け名_受領請求書.pdf
```

破損やパスワード付きなど結合できないPDFは個別に保管し、一覧に結合不可と表示します。旧版はアプリ内の履歴に保持します。従来の証憑ZIP出力では原本・履歴も保存できます。

## 既存データを保持する更新

公開ZIPは更新専用です。DB、会社・口座の登録情報、社印、実取引の帳票、実パスワードを含みません。

1. 利用中アプリの「設定 → バックアップ」で全体バックアップを保存します。外部のPDFコピー先も保管してください。
2. LOGIBOXを終了し、新しいZIPを利用中フォルダとは別の場所へ展開します。
3. Windowsは新しいZIP内の `logibox/update.bat` を開き、現在のデータがある利用中の `logibox` フォルダを選択します。
4. 更新ツールは停止状態と配布ファイルを確認し、フォルダ全体を隣接する `LOGIBOX-before-0.7.0-*/full-installation.zip` へ保存・照合してからコードを更新します。
5. 更新後は利用中フォルダの `起動.vbs` を開き、ver.0.70の表示を確認します。初回起動時に既存の自動保存PDFをバックアップして案件フォルダへ整理します。
6. 「設定 → 会社情報を編集」で口座を登録し、請求書の仮プレビューで振込先を確認してください。

Python 3.10以降が必要です。Macは `python3 update.py --target "/path/to/current/logibox"` で更新し、`start.command` で起動します。`APP_DATA`で保存先を変更している場合は自動更新を中止します。

利用中の固定PDFテンプレート、DB・原本・旧版履歴は保持します。手動で保存・編集したファイルは上書きせず別名で出力します。公開テンプレートの固定宛名・住所は匿名化され、新規ハーク請求書の既定宛名は「請求先」です。テスト用データは架空です。
