## 元金請求書の修正

請求額は **担当元金 − 確定済み元金充当額（他案件・一時預かり金）** です。銀行振込・現金手渡しの実入金は控除しません。超過時は請求額0円とし、超過充当額を表示します。

- 元金管理と帳票で共通の計算・確定充当明細を使用。帳票に自動計算の内訳と請求額を表示。
- 青系PDF・御中を維持し、充当元番号・案件名・確定額・確定日・履歴を表示。
- 発行時の金額とPDFを固定。実入金は入金残高に反映し、請求額は変更しません。
- 同一案件・下請けの元金請求書の二重発行を防止。変更は明示した訂正・再発行で旧版PDFを保存。
- 発行日より後の確定充当を除外。過去日の旧方式充当を安全に再構成できない場合は確認を要求。

SP25236の条件（担当元金400万円、SP23648からの確定充当200万円）を一時DBで再現し、請求額200万円、プレビューと正式PDFの一致を確認しました。PC上の実データはこの作業環境にないため、実案件DBの直接確認・更新は行っていません。

## 既存データを保持する更新

**DB・パスワード・社印・案件・発行済みPDF・バックアップを含まない更新専用パッケージです。**

1. 利用中アプリの「設定→バックアップ」で全体バックアップを保存。外部PDFコピー先も保管します。
2. PCを再起動し、LOGIBOXはまだ開きません。
3. 新ZIPを利用中フォルダとは別の場所へ展開し、`logibox/update.bat`を開きます（Python 3.10以降）。
4. 現在データがある利用中の`logibox`フォルダを選択します（`data/app.db`が必要）。
5. 更新ツールは停止状態・配布物を確認し、利用中フォルダ全体を隣接する`LOGIBOX-before-0.6.8-*/full-installation.zip`へ保存・照合した後、コードだけを更新します。
6. 更新済みの利用中フォルダの`起動.vbs`を開き、ver.0.68と案件・元金・充当・入金履歴・PDFを確認します。

誤った金額の発行済み元金請求書は「履歴・編集」から「確定充当を再取得して金額を訂正する」を選び、発行日と仮プレビューを確認して再発行します。通常の備考編集では金額を維持します。

`APP_DATA`で保存先を変更している場合、自動更新は中止します。環境変数を消さず、管理者が実データ保存先を確認してください。詳しい復旧手順は同梱の更新手順を参照してください。
