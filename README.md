## 今回の修正

- ハーク請求書の商品詳細を復元し、長文・多数商品は続きページへ表示。
- 発行者社名右端に社印を重ね、白背景を透明化して原本を保存。今後のPNG登録にも対応。
- 元金請求書は最新の確定充当承諾日から本日まで発行日を選択可能。承諾日欠落は確認を促す。
- 現金入金を請求額から控除しない既存計算と、発行済みPDF・旧版履歴を維持。
- Mac用 `start.command` を追加。Windowsの起動・更新機能を維持。
- 利用中の固定PDFテンプレートは、更新で上書きせず保持。

## 既存データを保持する更新

**更新専用です。会社・下請け・仕入先の登録データ、DB、実パスワード、社印、実取引履歴、発行済みPDF、バックアップを含みません。**

1. 利用中アプリの「設定→バックアップ」で全体バックアップを保存します。外部のPDFコピー先も保管してください。
2. PCを再起動し、LOGIBOXはまだ開きません。ブラウザを閉じるだけでは旧サーバーは終了しません。
3. 新しいZIPを利用中フォルダとは別の場所へ展開し、`logibox/update.bat`を開きます。Python 3.10以降が必要です。
4. 現在のデータがある利用中の`logibox`フォルダを選択します。`data/app.db`が必要です。
5. 更新ツールは停止状態・配布ファイルを確認し、フォルダ全体を隣接する`LOGIBOX-before-0.6.9-*/full-installation.zip`へ保存・照合してからコードを更新します。
6. 更新後は利用中フォルダの`起動.vbs`を開き、ver.0.69の表示と既存データ・PDFを確認します。

`APP_DATA`で保存先を変更している場合は自動更新を中止します。管理者が保存先とバックアップを確認してください。空の更新パッケージから起動しても新しいDBは作成しません。

公開用に、固定の帳票宛先・住所と、テスト・文書の顧客固有の名前・案件番号を除去・匿名化しました。請求書テンプレートに会社情報や社印はありません。新規ハーク請求書の固定宛名は「請求先」となります。既存の発行済みPDF・保存済みスナップショットは変更しません。テスト用の架空データ・ダミーパスワードと、対応帳票形式の識別名・画面の業務ラベルはソースに含みます。
