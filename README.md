## ver.0.74

設定のバックアップ画面から、全体バックアップZIPを選択して業務データを置き換え復元できます。案件・取引・元金・精算・社印・会社情報・採番情報・添付と発行済み原本を引き継ぎます。

- ZIPの破損・不正パス・外部リンク・重複名・DB整合性・互換性を確認し、コピー上でDBを自動更新します。
- 日時・件数・復元できない項目を表示し、確認後に現在の全体バックアップを自動保存して復元します。
- 復元中の二重操作を防ぎ、失敗時は自動復旧します。プロセスが中断した場合は次回起動時に復旧します。
- 同じZIPでも追加登録せず置き換えます。移行先のパスワードを維持し、復元後は再ログインします。
- PDFコピー先は既定へ戻し、このPCで再設定できます。原本は旧PCの絶対パスに依存しません。
- 新形式では固定帳票テンプレートと参照先の変更前DBも含めます。旧ZIPに存在しない原本は警告し、推測で生成しません。

利益・元金の計算、月末締め翌月15日払い、都度精算、固定帳票の描画内容、管理番号・帳票番号のルールは維持します。

## 更新・移行

既存PCは更新専用ZIPから利用中のフォルダを更新してください。新規PCには配布用ZIPを使います。公開ZIPには業務DB・社印・発行済み原本・認証情報を含めません。

旧形式は `app.db`・`files/`・`documents/` を含む全体バックアップに対応します。ZIP上限180MB、展開後1GB、20,000ファイル。DB単体・暗号化ZIP・アプリ配布ZIPは復元できません。
